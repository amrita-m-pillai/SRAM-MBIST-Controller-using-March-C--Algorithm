# SRAM-MBIST-Controller-using-March-C--Algorithm
Designed an FSM-based SRAM Built-In Self-Test (MBIST) controller using Verilog HDL, implementing the March C- algorithm for automated memory fault detection. Developed modular RTL for address generation, memory control, data comparison, and error logging, and verified the design through simulation targeting Spartan-7 FPGA implementation.
